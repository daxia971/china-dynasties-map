# 中国朝代更迭图鉴 China Dynasties Atlas

交互式单页网站：在今日省界底图上展示历代王朝疆域变迁、关键历史事件、都城变迁与两千年分合大势。纯前端零依赖，离线可用。

**在线访问**: https://daxia971.github.io/china-dynasties-map/

## 四个维度

| 维度 | 内容 |
|---|---|
| 朝代疆域 | 18 格朝代时间轴（夏→清→近现代），每朝版图示意 + 都城 ★ + 大事记；并立时代画多政权（三国魏蜀吴、宋辽西夏、南宋金、明含羁縻都司），秦汉明附长城走向 |
| 关键事件 | 26 个改变历史走向的节点按发生地落图（牧野、长平、赤壁、澶渊、靖康、崖山、土木堡、尼布楚、武昌起义……），按七个时代着色 |
| 都城变迁 | 四大古都 + 开封、杭州、安阳、邺城、银川、盛京等 14 座都城，各配建都逻辑与典故 |
| 统一与分裂 | 前221–1912 分合大势图（大一统/南北并立/群雄割据三色分段）+ 王朝国祚排行 |

## 交互

- 顶部时间轴点选朝代，面板支持"上一朝/下一朝"连续翻阅
- 点击版图/星标/事件点/图表色块 → 右侧面板显示详情（带涟漪动效与选中高亮）
- 悬停任意对象显示提示

## 技术与声明

- 纯 HTML + SVG + 原生 JS，无框架无外部依赖
- 底图省界：阿里云 DataV.GeoAtlas 公开 GeoJSON（简化示意）
- **历代疆域为盛期约略示意**：历史边界存在学术争议与年代变动，羁縻/藩属与实际控制差异很大，仅供学习参考

## 本地运行

把 `index.html` 和 `china-geo.js` 放同一目录，双击 `index.html` 即可。
